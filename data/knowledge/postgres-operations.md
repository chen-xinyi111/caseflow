# PostgreSQL 连接与数据库停止

## 数据职责
实验数据库保存任务编号、请求编号、原文、状态、统计结果和处理版本。API 提交和查询都需要数据库连接。正常实验实例与故障实验实例使用独立数据库、网络和数据卷。

## 停止表现
postgres 容器停止后，业务请求不能保存或读取任务。实验 API 捕获数据库异常并返回 HTTP 503，提示实验数据库不可达。健康探针 /health 只表示 API 进程在线，不代表数据库一定正常。

## 只读核对
核对容器状态、API 日志中的数据库不可达提示，以及诊断中的 database.reachable。不要将用户任务等待直接等同于数据库停止；若 postgres 仍运行，需要进一步排查连接配置或事务等待。
