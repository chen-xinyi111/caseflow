# 使用 OpsLens

工作台显示登记项目的实时容器查询结果、最近采集时间及调查记录。刷新只读取状态，不采集完整日志，也不发送模型请求。没有容器、服务停止、健康检查异常和无法查询分别如实显示。

## 调查项目

选择项目并填写问题 → 采集并预览资料 → 核对脱敏原文及选中范围 → 确认发送百炼北京 → 开始调查。

日志可取消选中。至少保留一项成功采集的运行证据；更改选中范围、重新采集或刷新页面均清除勾选确认。用户问题也会随调查发送，请勿填写密钥或不希望发送的业务资料。自动脱敏不能替代你对内容的检查。

资料确认绑定固定快照和选中内容。模型只能读取这份快照和选中项目资料，不能访问其他项目或业务数据库。结论限定采集时刻，需要新证据时重新采集确认；不会通过重复读取旧快照伪装为新补查。模型额度不足或核验记录失效时停止，不付费降级。

报告优先展示结论、事实与依据、缺少资料和下一步建议。可打开原文；分工、核验过程与调用详情在折叠区域。信息不足时不强行确认原因，外部项目只给人工处理建议。

## 资料和项目管理

调查页面“管理接入项目与资料”可登记本机 Compose 项目名、允许采集状态的服务、允许采集日志的服务。仅登记精确名称，不自动匹配相似名字。每个日志来源限定最近80行、脱敏后最多64KiB；没有登记日志服务则不采日志。

项目资料以标题和正文保存，旧版本保留；新版本仅在重新采集后进入新快照，不加入已确认快照。其他项目没有手册时如实说明，不借用实验手册证明业务现状。当前不读取任务详情、数据库、容器环境变量或文件挂载内容，不执行容器命令。

知识库提供原有版本化文档检索与原文查看；导入及索引管理在折叠区域。外部项目专属资料与知识库实验资料分开，外部调查只检索所选项目资料。

## 历史与恢复

“维护与记录”可打开原演示、评测、测试任务和故障案例。日常调查列表默认排除旧演示和来源未标注的历史记录，勾选“包含历史与示例记录”可找回；没有删除任何报告。

只有核验通过的故障实验调查才显示“审阅恢复方案”。需要你批准具体版本，执行前再复核，过期或状态变化时停止。青禾和其他外部项目不会出现恢复执行入口，直接调用恢复 API 也会被拒绝。

桌面及窄屏均保留四项主导航与维护入口；引用原文对话框支持键盘 Tab 和 Escape。
