# 隔离实验演示

演示用于体验有依据的调查、信息不足时停止、人工审批和业务验证。演示调查与核验使用明确标注的可控响应，运行状态、任务、证据原文和业务探针来自真实隔离实验；它不代表真实模型效果。

## 准备环境

```powershell
./scripts/local/Start.ps1 -Scope Fault
```

实验演示需要已经建立的知识索引。先在知识库导入内置手册并完成语义索引设置；构建语义索引需自己的模型配置、有效额度核验和资料发送确认。缺少索引时演示准备会停止，源码不会附带维护者的索引或记录。

```powershell
./scripts/local/Demo.ps1
```

准备脚本在独立故障实验中停止 worker 并准备排队任务，保存可控示例调查；不批准恢复，不改变正常实验和外部项目。存在未完成调查或执行中的恢复时会停止。仅需重启平台时使用 `RestartPlatform.ps1`，避免再次启动实验服务改变已准备的故障。

## 页面体验

1. 打开“维护与记录 → 示例记录 → 打开成功调查”，查看采集时的 worker 状态、任务及手册依据，并打开引用原文。
2. 审阅恢复方案，确认作用范围、版本和固定动作；生成方案只读状态，批准前不修改服务。
3. 由使用者勾选并批准此版本，系统复核后启动实验 worker，用新任务验证业务结果，记录实际动作。
4. 查看信息不足示例，了解缺少运行资料时的停止原因与补充建议；该记录不能生成恢复方案。
5. 已有本机评测结果时，可进入对照评测查看原回答、规则评分、事实复核与失败。新克隆不会自动具备这些结果。

批准后故障 worker 状态会变化。再次演示需要重新准备，旧报告和动作记录保留；历史结论描述原采集时刻，不能据此直接执行过期方案。
