# 本机备份与恢复

停止页面不会停止数据库中的后台任务。备份前等待任务结束，再运行：

```powershell
./scripts/local/Backup.ps1 -VerifyRestore
```

脚本暂停平台，创建PostgreSQL完整备份，将备份恢复到独立临时数据库并逐表核对记录指纹，随后恢复平台。源代码快照以当前Git提交为准，未提交的重要修改须先保存。输出位于本机.archives，不进入仓库。

.env与API Key须独立安全保存，不要发布数据库备份和模型调用原文。恢复正式数据库前应停止工作器，先在独立实例验证，保留当前数据库副本，再按自己的部署环境恢复。验证备份可恢复，不代表可以直接覆盖正在使用的数据库。
