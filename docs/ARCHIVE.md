# 私有备份与还原

调查、证据、审批、动作和评测结果保存在平台 PostgreSQL 中，部分模型原始资料保存在 `.runtime`。Git 源码不是数据库备份，克隆公开仓库不会恢复这些本机记录。

## 创建备份

```powershell
./scripts/local/Backup.ps1 -VerifyRestore
```

备份前等待活动任务结束。脚本只暂停平台进程，保持数据库和接入项目运行状态，导出一致性数据库备份，并生成文件清单及表级摘要。验证时创建独立数据库，使用 `pg_restore --exit-on-error --no-owner --no-privileges` 还原，不启动任务处理器。完成后默认重新启动平台。

归档写入 `.archives` 中新的时间戳目录，不覆盖已有备份。不打包 `.env`、密钥、账户截图或依赖目录；归档仍可能包含原始业务资料，应私有保存。复制到其他磁盘后核对清单摘要。

## 还原与核对

验证归档 manifest 的文件摘要，在新的 PostgreSQL 16 / pgvector 空数据库中还原，不覆盖当前数据库。核对表级数量与内容摘要，单独配置本机密钥。归档内 `RESTORE.md` 记录还原步骤。

验证数据库不会自动替换当前数据库。启动还原环境前检查未终结动作和结果未知的模型请求，避免重发。

## 冻结实现

`data/evaluation/source-v1` 保存冻结实现的精确字节，`.gitattributes` 禁止换行转换；摘要与 manifest 一致。新的公开 Git 历史不会改变旧文件的来源提交字段。后续评测应封存实际执行的源码，不能把升级实现当作历史实现。
