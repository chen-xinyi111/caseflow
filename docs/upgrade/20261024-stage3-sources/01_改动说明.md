# 第三阶段改动说明

日期：2026-10-24。本文“实现”指源码行为；实际运行证据以[验证记录](02_验证记录.md)为准。

## 原件、规范文本与不可变版本

新文件保留上传bytes与SHA256，粘贴保留提交正文的UTF-8字节；规范文本经既有清理、脱敏和LF统一后固定。两种摘要分开保存，不能以清理后文字相同复用不同原件。既有document_id就是版本ID，更新创建新ID并保留previous_id。cf_document_versions和cf_evidence只追加，UPDATE/DELETE触发器拒绝原地改写；本轮未在真实库验证触发器。

新增资料与原件侧表在同一事务保存，沿用项目行锁和revision冲突检查。解析错误、修订冲突、侧表冲突不应留下部分项目资产。旧资料GET只读取既有pages，统一标记legacy_text，不根据.pdf文件名推定物理页。显式迁移只追加侧表；旧JSON、规则、编号、人工编辑与历史不重写。

PDF以实际提取页为单元，空白页仍占真实页号；Word保留段落/表格段落，MD/TXT按段落，均不编物理页。规范快照包含pages、units、单元绝对范围、文本与定位口径。解析签名只描述生成规则；读取旧版和索引投影优先使用已冻结侧表，更新解析代码不会重新解析已保存版本。

## 精确证据与页面

引用由项目、文档ID、快照SHA256、有序unit_id/start/end及逐字quote约束。偏移从0开始，结束不包含，单位为Unicode code point；Python与前端Array.from一致，组合字符不作隐式归一化。bool、越界、重叠、倒序、快照不匹配或改写引文会被拒绝。多片段使用`[…片段分隔…]`明确隔开，未引用的中间文字不伪装成连续依据。

旧page/quote保留。精确匹配返回候选，重复文字必须人工选择；无匹配显示未定位，不模糊猜测。程序用稳定UUID生成证据，重复保存相同区间幂等；证据创建不改变R/T正文或项目修订。归档可读，创建新精确证据需先恢复项目。

“资料与知识”列表显示当前/历史版本、原件、解析提示、索引状态和最近索引任务结果。阅读面板提供原件链接、来源网址、位置选择、规范文本高亮与多片段保存。hash链接示例为`/#/projects/{pid}/documents/{did}?evidence={eid}`，直接进入时读取指定项目，不依赖上次项目偏好。错误文档或引用不切换到别的文档。PDF用原件iframe及规范文本同页展示，未实现PDF像素框高亮。浏览器不能内嵌显示时可打开原件；原件本身未脱敏，规范快照与原件须区别看待。

## 增量接口

所有路径位于`/api/v1/caseflow`；UUID和请求字段通过Pydantic校验。

| 方法/相对路径 | 用途 |
|---|---|
| GET /projects/{pid}/documents | 当前项目全部版本元数据及状态 |
| GET /projects/{pid}/documents/{did} | 固定版本快照，不在GET迁移 |
| GET /projects/{pid}/documents/{did}/original | 原字节，缺原件404；PDF inline，其他附件 |
| POST /projects/{pid}/evidence/resolve-legacy | 返回旧quote精确候选，不创建证据 |
| POST /projects/{pid}/evidence | 核验区间/文字并保存程序证据 |
| GET /projects/{pid}/evidence/{eid} | 核验并返回固定证据及阅读URL |

现有texts/files入口增加可选source_url元数据，不抓取网址；只接受不含凭据的HTTP/HTTPS。现有任务和生成协议仍保留；本阶段没有放宽模型准入。新增OpenAPI/前端生成类型已同步，SourceSegment避免与旧诊断Segment同名。

## 索引与主要文件

内部KB增加ingest_snapshot，直接按规范pages切块，保留page/start/end。检索命中逐字比对原快照对应区间，返回快照摘要与segments；去掉展平TXT后猜回页码的方式。派生TXT只供内部KB使用，不冒充原件。索引身份绑定成员版本、参数、模式及必要Embedding标识；ready可复用，失败显式重试，始终active=false，不使用全局active index。

上传、阅读、定位和迁移不触发索引或模型。建立资料索引仍沿用显式任务；原有已授权生成中的search_documents工具也可按所选范围构建投影，保持既有行为。关键词构建不调用Embedding；向量/重排仍走原模型额度与同意门槛，本轮没有执行。
