| 导入与组织资料 | S11 文件／文件夹入口、就绪与索引时间；S09 资料组；S01 知识入口 | 实际上传成功、解析失败、原件与版本保存、资料组和知识库关系 |
| 设置目标和依据范围 | S08 测试目标、三类文本输入；S02/S06 知识库与 Wiki 多选、附件引用 | 实际读取了哪些文档、范围隔离、遗漏提示与可检查的依据准备结果 |
| 提取测试点 | S06 开始提取按钮；S08 阶段空态；S07 已有 20 点 | 提取调用、过程事件、失败重试及输入到产物的关联 |
| 人工评审 | S07 独立会话、场景、卡片、意图、引文、单项与批量入口 | 编辑保存、通过／拒绝转换、复审、批量约束与持久化 |
| 原文回查 | S07 引文／文件名／p.1，S05 分页阅读器 | 点击引用后精确跳转、高亮、复制刷新、版本稳定及重复引文消歧 |
| 生成详细用例 | S07 生成用例(0)，S03 用例计数 | 实际生成、详细用例正文、测试点关系、生成后的审核和导出 |

因此可以把“目标与授权资料 → 测试点 → 人工评审 → 详细用例”作为借鉴方向，但不能声称已观察到参考站完整闭环。CaseFlow 的显式依据准备、不可变原文版本、更新后复审等要求来自用户已确认计划，不能倒写成参考截图已证实的功能。
