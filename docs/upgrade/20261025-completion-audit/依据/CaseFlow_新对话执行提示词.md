## 七、每段对话结束时的交接要求

如对话较长或需要更换对话，请在对应阶段输出目录新增交接记录，至少包含：

- 总计划和当前阶段，已完成内容与剩余内容。
- 实际工作路径、当前 Git 提交和用户原有修改的保护情况。
- 报告、设计、图示、代码及验证记录的真实位置。
- 已观察、源码已证、推测与未验证项。
- 实际检查命令及结果；没有执行的检查明确说明。
- 重要实现决策、兼容安排与下一阶段操作入口。
- 不在交接中保存密钥、账户凭据或私有模型原始调用内容。
