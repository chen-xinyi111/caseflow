## 失败与修复

- 实现核对中将依据指纹与编辑实体指纹分离，避免生成前后ID/修订差异使新复核过期；复核使用完整冻结依据，编辑继续检查实体版本。
- 固定变更实现中核对了接受新R后再次准备的重复风险，改为匹配精确证据复用原R，保留人工内容，不按仅文字跨版本合并。
- 扩展检查一轮在不可用复核的人工批准处返回409而预期400；单独复测不稳定。定位为随机hash含11位手机号形状数字被文本脱敏。API改为仅清洗prose字段，保留UUID/hash；固定含13812345678的hash回归，不削弱校验。
- 页面重绑后审核说明被缺省空字符串清除。API改为只采用显式提交字段，未提交新备注时保留原备注，并增加回归。
- 页面规则变化引用入口仍显示非PDF“第1页”，已改为复用资料类型定位标签；新用例导出也用冻结精确location_label，历史兼容列保留原行为。
- 一轮扩大完整回归390项中389通过、1个既有恢复测试`test_approval_execution_probe_and_duplicate_delivery_are_durable`预期completed却得到manual。本轮38个新增链路检查均通过；该旧测试单独复验1通过（3.24秒）。首次输出缺少计划错误细节，根因未证实；只补充原断言失败时的plan/actions/probes诊断，不改变断言或恢复业务逻辑。后续完整回归结果见最终摘要，不删除此失败记录，也不宣称已修复旧恢复模块。
- 后续一轮完整回归389通过、1失败，明确错误发生于故障注入之前的psycopg.connect：本机18385连接报TCP 10048（Address already in use）；不是原子提交断言失败。该故障注入用例单独复验1通过（5.08秒）。保留完整输出；不能仅据此证明此前旧恢复失败也是同一原因。最终验证包装器只在TCP建连失败且明确10048、尚无连接/SQL时最多重连两次（0.25/0.5秒），记录次数；不重试SQL、提交或模型调用，不改服务业务与断言。实际重连次数见最终摘要。
- 浏览器原生点击因任务轮询重绘/滚动出现超时，读取实际状态后使用有语义的稳定定位器完成；截图一次失败后重读状态重试成功。下载工具尽管设置短超时仍异常长时间占用，最终返回文件路径且内容核对成功；属于工具异常，不据此声称产品下载性能。
